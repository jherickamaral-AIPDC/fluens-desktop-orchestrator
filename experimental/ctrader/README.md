# Adaptador cTrader — referencia experimental

Esqueleto C# de puertos, kernel y pruebas. Se conserva separado del runtime y no participa en el preview.

**No es una integración operativa ni una biblioteca autónoma.** Requiere los namespaces externos `Fluens.LocalDemo.Core` y `Fluens.LocalDemo.Strategy`, que no pertenecen a la selección pública autorizada. No se incluyen ni se buscan fuera de esta copia.

El script histórico de compilación y sus rutas de instalación no se publican. No se afirma que las pruebas históricas hayan sido reproducidas aquí.

Este directorio no habilita SDK, cuentas, conexión a un bróker ni órdenes. Completar esas dependencias o construir una integración real sería trabajo independiente con su propia revisión.
